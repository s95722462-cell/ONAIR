# 온에어 (溫 On-Air) — 따뜻한 안내방송

아나운서처럼 또박또박, 온기 있는 안내방송을 만드는 무료 웹앱입니다. 설치 없이 `index.html` 하나로 동작합니다.

- 장소 14종: 아파트 · 지식산업센터·빌딩 · 학교 · 회사·공장 · 상가·마트 · 병원 · 교회 · 복지관 · 사찰 · 식당·카페 · 공항·역 · 예식장 · 공연장 · 관공서 (교회: 예배·찬양·헌금·새가족·식사·주차·예배 후 인사 전용 방송, 식당·카페: 주문·대기·포장 번호 호출 −1·+1·바로 호출, 휴게소 단체 버스·대형차·졸음운전, 🖥 TV용 호출 번호판 창, 📱 QR 휴대폰 알림)
- 방송 템플릿 70여 종 (한국어·영어·일본어·중국어 직접 작성) + 27개 언어 자동 번역
- Edge·Chrome 무료 AI 음성, 차임, 남·여 번갈아 읽기, 발음 사전, ✨ 문장 다듬기, 고친 문장 자동 저장
- 🎙 성우 억양: 시간·날짜·번호·장소를 조금 천천히 또렷하게, 문장 끝은 차분하게 (문장을 조각으로 나눠 빠르기·높이·쉼 조절) · 🎚 직접 표시 `[강조]…[/]` `[천천히]` `[빠르게]` `[높게]` `[낮게]` `[작게]` `[쉼]` `[긴쉼]`
- 예약 방송 · ⏱ 카운트다운 · 📚 방송 묶음 · 🖥 방송실 모드 (즐겨찾기 큰 버튼 · 번호 패드)
- 💾 음성 파일(MP3·WAV) · 📄 공지문 인쇄 · 💬 카톡 복사 · 📊 기록 엑셀 · 💼 백업 (매장 QR 코드·화면 설정까지)
- 📘 앱 안 사용 설명서 (⚙ 설정 탭 · 화면 아래 '사용 설명서' · 주소 끝 `#manual`) — 자주 묻는 질문 · 개인정보 포함

가장 자연스러운 목소리는 PC의 Microsoft Edge에서 나옵니다. 음성 읽기가 없는 브라우저(일부 앱 안 브라우저 등)에서도 앱은 열리고, 번호판 · QR · 공지문 · 카톡 복사 · 기록 · 백업은 그대로 쓸 수 있습니다.

## 개인정보

- 회원 가입·로그인 없음. 방송 문장·설정·기록은 사용하는 기기의 브라우저 저장소에만 저장됩니다.
- Edge 온라인(★★★) 목소리는 읽을 문장을 Microsoft 음성 서비스로 보내 소리로 바꿉니다.
- 📱 QR 휴대폰 알림은 무료 중계 서비스 ntfy.sh 를 거치며, 매장 코드와 주문 번호(와 시각)만 보냅니다.
